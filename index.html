规则何止简单？

数列从 0 和 1 开始，之后的每一项 都等于它前面 两项之和：

F(n) = F(n−1) + F(n−2)

这看起来稀松平常，但正是这条简单的规则，衍生出了植物器官排列、 贝壳的螺旋、甚至人类的骨骼比例等自然界中最普遍的美学模式。

Golden Ratio

黄金螺旋：永恒的优雅

当相邻两项的比值稳定下来，就得到约 1.618 的黄金比例 φ。用它画出矩形与圆弧，便构成了自然界随处可见的黄金螺旋。

为什么是 1.618？

将一条线段分成两部分，使整体与较长部分之比等于较长部分与短部分之比， 这个比值 φ = (1 + √5) / 2 ≈ 1.6180339887… 就是黄金比例。它也和斐波那契数列的极限比值完全一致。

从帕特农神庙到《蒙娜丽莎》，达·芬奇的作品，再到苹果公司的标志， 设计师们数百年来都痴迷于这个比例带来的和谐美感。

💡 左侧拼图的每个正方形边长依次为 1、1、2、3、5、8、13， 恰好是斐波那契数列。当它们拼合完毕，各正方形内的 90° 圆弧 便会连成自然界中那条完美的黄金螺旋。

The Math

从递推到封闭公式

除了逐项相加，还有一个惊人的事实：你可以直接用黄金比例 φ 算出任意一项——无需计算它之前的所有项。

F(n) = φn − (1−φ)n / √5

其中 φ = (1 + √5) / 2 ≈ 1.618，这就是著名的「比奈公式」，由法国数学家雅克·比奈于 1843 年发现。

斐波那契的惊人性质

这些性质让斐波那契数列成为数论与编程中的「明星」。

1

相邻项互质：相邻的两个斐波那契数最大公约数总是 1，即它们总是互质的。

2

平方和求和：前 n 项的平方和等于第 n 项与第 n+1 项的乘积：F₁²+…+Fₙ² = Fₙ·Fₙ₊₁。

3

可被整除：当且仅当 n 能整除 m 时，Fₙ 能整除 Fₘ。这使得斐波那契数列成为理解整除性的绝佳例证。

4

与编程：斐波那契是递归与动态规划的经典教学案例，也是测试性能与缓存技巧的常用基准。
